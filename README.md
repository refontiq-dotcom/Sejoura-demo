# Séjoura — Démo interactive complète

Démo UI/UX professionnelle de la plateforme **Séjoura** (gestion de résidences & hôtels).

## Contenu

- **index.html** — Landing page marketing (hero, features, pricing, témoignages, CTA)
- **dashboard.html** — Dashboard interactif complet
  - Sidebar responsive (drawer mobile)
  - Navigation multi-pages (Dashboard, Établissements, Chambres, Réservations, Ménage, Comptabilité, Employés, Abonnement, Paramètres)
  - KPIs, graphiques Chart.js, tableaux
  - Modal nouvelle réservation
  - Check-in / Check-out interactifs
  - Notifications, thème clair/sombre, toasts
  - Logout fonctionnel

## Comment ouvrir

1. Ouvrez `index.html` dans un navigateur moderne (Chrome, Firefox, Safari, Edge).
2. Cliquez sur **Essayer gratuitement** ou **Démo Dashboard** pour accéder au dashboard.
3. Ou double-cliquez directement sur `dashboard.html`.

Aucun serveur ni installation nécessaire (CDN Tailwind + Chart.js + Lucide).

## Stack de la démo

- HTML5 sémantique
- Tailwind CSS v3 (CDN)
- Chart.js 4
- Lucide Icons
- Vanilla JS (pas de framework)
- Dark mode persisté (localStorage)

## Design system

- Couleurs brand bleu (#0c8ce9)
- Typo : Plus Jakarta Sans (titres) + Inter (corps)
- Coins arrondis 2xl, ombres douces, micro-interactions

Créé en tant qu’expert développeur web & UI/UX designer pour illustrer la vision produit de Séjoura.
